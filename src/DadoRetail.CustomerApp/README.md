# DADO Customer App

Flutter-клиент магазина «ДАДО»: одежда, обувь, аксессуары, товары для дома и «1000 мелочей».

## Реализованный стартовый блок
- каркас Flutter приложения для iOS/Android;
- фирменная красно-белая тема;
- вход по номеру телефона;
- экран второго уровня авторизации OTP;
- нижняя навигация: Главная / Каталог / Корзина / Заказы / Профиль;
- стартовая витрина и категории;
- личный кабинет;
- DADO Wallet как отдельный раздел профиля;
- точки входа для способов оплаты, бонусов и безопасности.

## Следующие блоки
1. API-клиент и подключение к DadoRetail.Api.
2. Customer/Auth API: телефон, OTP, refresh token, trusted devices.
3. Каталог: категории, SKU, размеры, цвета, фото, остатки и поиск.
4. Корзина и оформление заказа.
5. Wallet/Ledger: баланс, пополнение, списание, возврат, история.
6. Эквайринг: payment intent, tokenized cards, QR, webhook confirmation.
7. Заказы, доставка, статусы и push-уведомления.
8. Биометрическое подтверждение на поддерживаемых устройствах.

## Важное правило платежей
Приложение не хранит PAN/CVV банковских карт. Финальный статус платежа устанавливается сервером после подтверждения платежного провайдера/webhook.
